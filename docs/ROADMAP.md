# Roadmap

1. Persistencia completa y autenticación SSO/productiva.
2. PWA offline con sincronización por intervalos.
3. Ingesta edge de presión, torque, RPM, agua, vibración y profundidad.
4. Telemetría temporal, MSE y reglas configurables.
5. Modelos de ROP, vida, desgaste y anomalías una vez exista evidencia suficiente.
6. Geología opcional con autorización, mantenimiento, ERP, API keys y webhooks.
